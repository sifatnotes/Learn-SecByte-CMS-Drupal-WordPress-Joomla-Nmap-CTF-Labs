# Learn SecByte CMS, Drupal, WordPress, Joomla & Nmap CTF Labs

A focused collection of **cybersecurity labs, CTF labs, hands-on cybersecurity labs, ethical hacking labs, and penetration testing labs** from Learn SecByte.

This collection covers practical **CMS reconnaissance, credential discovery, Drupal, Drupalgeddon2, WordPress, Joomla, CMS fingerprinting, shell stabilization, and Nmap network mapping**.

The labs are useful for cybersecurity students, CTF players, pentesters, SOC analysts, and security learners practicing application and network security in authorized environments.

## Learning Path

### 1. Learn General CMS Reconnaissance

Start with:

- CMS Trailhead
- CMS Fingerprint Forge
- CMS Trailblazer

Build familiarity with CMS identification and web reconnaissance.

### 2. Practice Platform-Specific Enumeration

Continue with:

- Drupal Detectives
- Drupal Drift Recon
- Joomla Hunt Enumerate the CMS
- CMS Trail WordPress Revealed

Explore reconnaissance approaches across different CMS platforms.

### 3. Study CMS Security

Then work through:

- CMS Cred Hunt
- Drupalgeddon2 CMS Breakout

Focus on credentials and the Drupalgeddon2-themed security scenario.

### 4. Practice Network Reconnaissance

- Nmap Cartography

Use this exercise to develop network mapping and Nmap-related reconnaissance skills.

### 5. Review Shell Concepts

- Shell Snap Stabilize the Session
- Shadows in Shells

Finish by practicing shell and session-handling concepts in the authorized lab environment.

## How to Use the Labs

1. Select a lab from the collection.
2. Read the exercise instructions before testing.
3. Work exclusively against the authorized CTF environment.
4. Start with systematic reconnaissance.
5. Record discovered CMS platforms, technologies, users, paths, services, and other findings.
6. Document the reasoning behind each step.
7. Review the defensive security lesson after completing the exercise.

Skills represented across this collection include:

- CMS reconnaissance
- CMS fingerprinting
- Drupal security
- Drupalgeddon2
- Joomla enumeration
- WordPress reconnaissance
- Credential discovery
- Nmap network mapping
- Shell stabilization
- Web enumeration
- CTF methodology
